# 可复用的生成 Prompt 模板

先完成三个板块分析，再套用以下模板。模板用【】标出需按具体作品填写的位置；全部为待测试模板，实际生成后才记录效果与不足。

## 模板 A · 生成新作品

参考附图制作一张【画幅，如 3:5 竖版】的正面平面【海报/插画】，画面中只有一张完整作品。视觉主题是「【关系命题或意象】」：像【一句话定位：把机制概括为画面结构】。重在【一句话概括该风格的核心张力，如受控失序 / 有限色与纪念碑尺度】。

【纸底色与主导色说明】统领线条、文字与主形，【辅助色】作局部填色，【强调色】只集中在极小的图像或线条上。纸纹轻微。

【主体构成：位置、尺度、轮廓状态、内部结构与肌理如何配合】。让主体在「图像」和「【印刷单元/剪影大形】」之间摇摆，周围留不均匀空隙。

【次级图形/模块：位置、尺度、与主体的视觉回声】。不同尺度、清晰度和载体反复出现，建立视觉回声。

文字作为主要图形材料，而非海报大标题。只使用这些文字作为字素库：【列出允许的文字】。说明其排版方式（重复、倒置、裁切、拉伸、疏密、印刷体与手迹反差）。手写短句只作边角批注，字母高低错落、间距忽密忽疏，笔迹细弱不规整；不要流畅连笔花体、不要居中励志大标题。微型文字的纹理节奏优先于逐字可读。

构图有隐形对齐轴，但模块尺寸、边距与朝向不同；少数轨迹越界，少数字形贴边裁切；以大形、中型图形与微型文字形成三到四个阅读尺度。整体像【整体气质，如松动而精密的私人印刷实验】。

避免：【逐条列出该风格要避免的雷区，如完整主体主视觉、巨大照片、漂亮书法、均匀装饰、等大等距、统一纹理、发光特效、金属质感、满版磨损、复制原作署名与句子、多张样机】。

## 模板 B · 输入素材转化

将输入图 A 作为内容来源，将输入图 B 作为色彩、排版与肌理参考。输出一张【画幅】正面平面作品。

保留 A 中【主体轮廓、姿态或关键识别结构】，将其概括为【该风格的核心表达方式，如单色半调主图 / 有少量浅色刻线的近黑大形】，移除背景杂物与真实材质反光。

以【故事关系或机制】决定尺度与布局，只选择一个机制：【列出可选机制，如斜向道路 / 波浪横带 / 连续变形螺旋 / 中央巨大负空间 / 三列网格】。如果关系是变化，用多个阶段沿一条路径展开；如果关系是敬畏，用几个小人物作尺度标尺；如果关系是孤独，优先保留空白。

【主色与纸色】统领明暗，【强调色】只放在有叙事意义的位置。人物脸部简化，通过姿态表达情绪。局部可有透视，整体按剪影与平面色块组织。主体内的刻线跟随结构，背景颗粒细而弱，保留安静暗部。

只加入指定文字【短句】和【小字标签】；短句使用真实手写般的不均匀笔触，小字使用清晰印刷体。产品标志如需准确保留，留位后期排版，不重新编造。

借鉴 B 的视觉组织方式，不搬用其标志、原句和具体版面。不额外添加【无关元素】；装饰从输入主体形状中推导。成品为单张平面稿，非纸张摄影样机。

禁止：直接给照片套旧纸滤镜，默认添加【该风格常见但此处不成立的元素】，无关历史/文化装饰。

## 评审重点清单

生成或复刻后，逐条检查：

- 去掉主题素材与旧纸肌理后，构图是否仍成立？
- 缩小后是否有唯一焦点；放大后是否有异质细节？
- 主体识别是否靠大形/点阵，而不是靠完整写实轮廓？
- 强调色是否有明确职责，而不是均匀点缀？
- 手写是否局部破格且仍可读？
- 暗部/留白是否保留了安静区，没有被细节填满？
- 是否误把多张参考的构图混成一个模板？
- 文字、符号与主题是否互相呼应？
